## 🔴 Fix Karo (Issues Found — priority order)

### 1. ✅ FIXED (PR #302) — Duplicate brand in title — `/articles/hi`
**Page:** https://kisanstatus.com/articles/hi
**Title abhi:** `हिंदी योजना गाइड — 16 आसान गाइड | KisanStatus | KisanStatus`
**Problem:** "KisanStatus" do baar aa raha hai — layout template bhi suffix add kar raha hai aur page title mein bhi likha hai. SERP mein unprofessional dikhta hai.
**Fix (Next.js):** Page ke `metadata` mein title se `| KisanStatus` hatao, ya layout ka `title.template` use karo:
```ts
// app/articles/hi/page.tsx
export const metadata = {
  title: 'हिंदी योजना गाइड — 16 आसान गाइड',  // template khud "| KisanStatus" lagayega
}
```
**Note:** Baaki sab pages check kiye — sirf isi page pe ye bug hai. Lekin repo mein search karo `| KisanStatus` hardcoded strings ke lye jahan template bhi apply hota hai.

### 2. ✅ FIXED (PR #302) — Mixed-case URLs (24 article URLs)
**Example:** `/articles/KisanRinKahaSeLe2026`, `/articles/PmKisanEkycOnline2026`
**Problem:**
- Lowercase version (`/articles/kisanrinkahasele2026`) **404 deta hai** — agar koi lowercase mein link kare (social media, WhatsApp forwards mein common hai) to backlink waste + user ko 404.
- SEO best practice: lowercase, hyphen-separated slugs (`kisan-rin-kaha-se-le-2026`).
**Fix options:**
- **Minimum (recommended, safe):** Middleware add karo jo case-insensitive match karke canonical URL pe 308 redirect kare. Purane URLs change mat karo (ranking loss risk).
- **Full fix (optional, riskier):** Naye articles ke lye lowercase-hyphen slugs adopt karo; purane URLs as-is rehne do.
```ts
// middleware.ts — lowercase redirect for /articles/*
// (sirf tab jab exact-case route 404 hota; slug map se match karo)
```

### 3. ✅ FIXED (PR #302) — Sitemap `lastmod` sab pages pe same/auto-bumped
**Problem:** Homepage, `/articles`, `/rajya-yojana` sab ka `lastmod=2026-08-14T03:45` (aaj ka build time). Agar har deploy pe sab dates bump hoti hain to Google `lastmod` pe trust karna band kar deta hai (Google ne officially kaha hai — unreliable lastmod ignore hota hai) → naye content ki fast indexing ka benefit chala jata hai.
**Fix:** `lastmod` sirf tab update karo jab page ka **content** actually change ho — article ke frontmatter/DB `updatedAt` se lo, build time se nahi.

### 4. ✅ FIXED (PR #302) — hreflang incomplete (Notice)
**Problem:** Sitemap mein sirf homepage pe `hreflang="hi-IN"` hai; HTML pages mein hreflang links hain hi nahi. `html lang="hi-IN"` set hai, but kai articles Hinglish/English mixed hain.
**Fix:** Single-language site ke lye hreflang ki zaroorat nahi — ya to consistently sab URLs pe lagao (self-referencing `hi-IN` + `x-default`), ya sitemap se wo ek stray entry hata do. Half-done hreflang se koi fayda nahi.

### 5. 💡 Category pages thin hain (Notice)
**Pages:** `/articles/category/*` (6 pages) — sirf ~260–380 words.
**Problem:** Ye listing pages hain to thin hona normal hai, lekin ranking potential waste ho raha hai.
**Fix (optional):** Har category page pe 150–250 words ka intro paragraph add karo (e.g. "Kisan loan guides 2026: KCC, tractor loan..." + FAQ). Template-level change, ek baar mein sab 6 fix.

### 6. 💡 Title mein "2026" hardcoded (future maintenance flag)
**Problem:** Homepage title "PM Kisan Status Check 2026", aur ek article "PmKisan25viKist**2027**" already hai. Year-based titles CTR ke lye achhe hain, **lekin** Jan 2027 mein sab stale ho jayenge — Google stale-year titles ko demote karta hai.
**Fix:** Abhi kuch nahi — bas December mein yaad rakhna ki titles + slugs ka year-refresh plan chahiye (slugs mat badalna, sirf titles/content).
